# LBSA — boutique de vêtements

Site e-commerce statique (HTML/CSS/JS, sans dépendances) pour une marque de vêtements marocaine.

- Catalogue avec filtres (Homme, Femme, Traditionnel, Accessoires) et choix de taille
- Panier persistant (localStorage), quantités, livraison offerte dès 500 DH
- Commande avec paiement à la livraison (nom, téléphone, ville, adresse)

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages sur la branche.
Les produits se modifient dans le tableau `PRODUCTS` du script.
